ASSETS
  There are none. Every texture, sprite, colour and sound is generated by
  first-party code in this repository at boot. No fonts, no images, no samples.

NETWORK
  Two requests the page did not serve itself: the Cloudflare Web Analytics
  beacon (cookie-less, anonymous page-view counts) and the hosted feedback
  widget. A multiplayer room adds a public WebRTC signalling relay, which
  introduces two browsers and then carries nothing. No game state reaches a
  server.
