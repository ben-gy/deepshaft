## Assets

There are none. Every wall texture, sprite, colour and sound in Deepshaft is
generated by first-party code in this repository — the wall and floor textures are
plotted into typed arrays by `src/textures.ts` at boot, the enemies and pickups are
drawn as vector shapes by `src/sprites.ts`, the icons are plotted pixel by pixel by
`scripts/gen-icons.mjs`, and every sound is a Web Audio oscillator described in
`src/cues.ts`. No fonts, no image files, no samples, nothing downloaded at runtime.

## Network

The page makes exactly two requests it did not serve itself: the Cloudflare Web
Analytics beacon (cookie-less, anonymous page-view counts) and the hosted feedback
widget. A multiplayer room adds a public WebRTC signalling relay, which introduces
two browsers to each other and then carries nothing. No game state ever reaches a
server.
